# Unverified images, do not publish

The three images in this folder came from the AI Bootcamp repository, where
they sat at the top level with no README entry, no session log entry and no
record of how they were made. They look like AI generated pub interiors.

They are kept because they may be useful, and they are quarantined because
nobody has written down where they came from.

## Before any of these goes on the site

1. **Confirm how it was made.** Only Joanna knows. If it was generated, say so.
2. **Add the AI disclosure line**, which is a standing Brand Bible rule whose
   wording is still to be written.
3. **Write alt text**, which is a standing rule with no exceptions.

## The reason this matters more than it looks

The site exists to tell a stranger what the room will be like on the night, so
they can decide whether to walk into a pub alone. A generated picture of a pub
that is not the venue answers that question dishonestly, and it is the one
question the page most needs to answer honestly.

The content plan already says this about the Thursday post: a real photograph
of the real room, taken on a phone when the booking is confirmed, beats
anything generated. The same applies here. **The right fix is a photograph of
the actual pub**, not a decision about which of these three to use.
