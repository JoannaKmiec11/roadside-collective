The cyclo-cross card is here as a worked example of the brand applied
correctly, which is more use to a build tool than a description. Note what it
does with colour: it is a deep purple ground, so flame orange is allowed on it.
The four cream cards in the same carousel carry no orange text at all, because
orange on cream fails AA. That contrast is the rule in BRAND.md in practice.
