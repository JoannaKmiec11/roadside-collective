# Logo files

**The logo is never redesigned, only converted.** If you need a size, a format
or a background that is not here, convert one of these files. Do not regenerate
it and do not ask an image model for something similar.

The design is Mix 3, "Banner at the roadside": ROADSIDE in ink on a slanted
flame orange banner, like the ones fans hang along the road, over a strip of
road with a dashed orange centre line, and COLLECTIVE underneath.

| File | Use it for |
| --- | --- |
| `roadside-collective-logo-on-cream.svg` | The default. Any cream or light section. Prefer the SVG on the web |
| `roadside-collective-logo-on-cream.png` | Where SVG is not accepted, for example some social uploads |
| `roadside-collective-logo-on-purple.svg` | Any deep purple or dark section |
| `roadside-collective-logo-on-purple.png` | The same, as a raster |
| `roadside-collective-logo-transparent-light-bg.png` | Over a photograph that is light. Has the banner bar |
| `roadside-collective-logo-transparent-dark-bg.png` | Over a photograph that is dark. Has the banner bar |
| `roadside-collective-logo-transparent-light-bg-no-bar.png` | Light photograph, where the banner bar clashes with the image |
| `roadside-collective-logo-transparent-dark-bg-no-bar.png` | Dark photograph, same reason |
| `roadside-collective-profile-picture.svg` | Instagram and Substack avatars. RC on the banner, square |
| `roadside-collective-profile-picture.png` | The same, as a raster |

## Picking one

Match the file to the ground it sits on, rather than picking the transparent
version by default. The on cream and on purple files are built for their
grounds and will always look right. The transparent ones are for photographs,
where you have to judge whether the image behind the logo is light or dark.

For a favicon and a social share image, start from
`roadside-collective-profile-picture.svg`. That is a conversion, which is
allowed.
